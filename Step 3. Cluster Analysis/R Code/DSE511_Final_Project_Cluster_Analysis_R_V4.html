Cluster Analysis

I. Hierarchical

Assumptions

  • Data must be numeric or convertible to a distance metric

  • Variables must be on comparable scales (standardized variables)

  • Data should have some natural separation, the structure cannot be completely random

  • Variables can be non-parametric

Limitations encountered: hclust() function in base R could not handle more than 65,536 observations (the dataset has 66,713).

II. K-Means

Assumptions: continuous variables with Euclidean distances.

Limitations: our data fail these assumptions because they are discrete, right-skewed, and Poisson/logarithmically distributed. Thus, we cannot perform a k-means cluster analysis.

Notes: I explored this option regardless of failing the assumptions in the DSE511_Final_Project_Cluster_Analysis_V3.

III. K-Modes

Assumptions

  • Variables must be categorical

  • Variables must not have any missing data

  • Categories must have a mode (most frequent category) as their center

  • Categories must have a similar size/density

Limitations: None!

Notes: some categorical variables only apply to some of the observations; thus, we will replace NAs with “Not Applicable”.

For each size, plot the cost function (i.e. within-cluster dissimilarities) against the number of clusters (k) to identify the elbow point

# Extract within-cluster dissimilarities (cost) by cluster size
kmodes_costs <- sapply(
  kmodes_results,
  function(x) sum(as.numeric(x$withindiff))
)

plot(
  1:10, kmodes_costs, type = "b",
  xlab = "Number of clusters (k)",
  ylab = "Within-cluster dissimilarity (cost)",
  main = "k-modes cost vs number of clusters"
)

Identify the elbow point in the plot, where the rate of decrease in the cost function significanlty slows down; this point suggests the optimal number of clusters.

It seems like 2 clusters could be sufficient but 2-6 clusters have a similar cost.

Since it’s hard to determine what cluster size to use, let’s narrow our results by omitting clusters with very small sizes

library(ggplot2)
library(dplyr)

# Helper function
plot_cluster_comp <- function(data, var_name) {
  ggplot(
    data,
    aes(x = .data[[var_name]], fill = cluster)
  ) +
    geom_bar(position = "fill") +           # proportion within each category
    coord_flip() +
    theme_minimal(base_size = 12) +
    labs(
      title = paste("Cluster Composition by", var_name),
      x = var_name,
      y = "Proportion"
    ) +
    theme(
      legend.position = "bottom",
      axis.text.y = element_text(size = 8)
    )
}

# By region
plot_cluster_comp(kmodes_df_2, "Region")

# By season
plot_cluster_comp(kmodes_df_2, "Season")
