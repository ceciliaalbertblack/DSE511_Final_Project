2. Handling Missing Data

A. Removing Variables

  • Serotype or Genotype: many observations are a list of several types, might be hard to use this data.

  • Etiology Status: many observations are a list of several confirmed/suspected statuses by serotype or genotype, which would be hard to use.

  • IFSAC Category: redundant to Primary Mode and Food Type.

  • Food Contaminated Ingredient: redundant variable, Food Type is enough.

  • Info on Hospitalizations: not actually indicative of hospitalizations.

  • Info on Deaths: not actually indicative of deaths.

outbreak_df <- outbreak_df %>%
  select(
    -'Serotype or Genotype',

B. Impute NAs

  • Food Vehicle: NA values for Food Vehicle falling under the Food as Primary Mode of outbreak will be replaced by “Unknown”.

  • Water Exposure: leave NAs because this variable does not apply to non-waterborne outbreaks.

  • Water Type: leave NAs because this variable does not apply to non-waterborne outbreaks.

  • Animal Type: leave NAs because this variable does not apply to non-animal associated outbreaks.

  • Illnesses: replace NAs with 0 because we found that most NAs were associated with Water as the primary source of exposure, meaning water-born pathogens likely were detected before they resulted in any illnesses.

  • Hospitalizations: replace NAs with 0, assuming no reported hospitalizations means none were reported with the outbreak.

  • Deaths: replace NAs with 0, assuming no reported deaths means no deaths were associated with the outbreak.

outbreak_df <- outbreak_df %>%
  mutate(
    `Food Vehicle` = 
      case_when(
      is.na(`Food Vehicle`) & 
        str_detect(`Primary Mode`, regex("Food", ignore_case = TRUE)) ~ "Unknown",
      TRUE ~ `Food Vehicle`
    ),

    Illnesses = if_else(is.na(Illnesses), 0, Illnesses),
    
    Hospitalizations = if_else(is.na(Hospitalizations), 0, Hospitalizations),

    Deaths = if_else(is.na(Deaths), 0, Deaths)
  )
